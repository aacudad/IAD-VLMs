# Explainability / Faithfulness Evaluation — IAD-R1 vs. Arm-C (ours)

**Date:** 2026-06-16 · **Script:** `repository_tu_delft_vlms/scripts/explainability_judge.py`
**Judge:** Gemini-3-Flash (`gemini-3-flash-preview`, Vertex AI, thinking_budget=512), single sample (k=1).

## Question
Given two models that **both correctly detect** the same anomaly, **whose reasoning/explanation is more faithful to the actual visual evidence?** Detection accuracy (BA) cannot answer this; this eval scores the *explanation* directly.

## Design (matched, fair, blind)
- **Anomaly traces only** = GT `answer=yes` AND a ground-truth mask exists.
- **Both models correct** = on the *same* image, IAD-R1 and Arm-C both predict `yes` (matched-pair intersection).
- **Best run of each:** ours = **Arm-C SFT, 82.8** (ckpt-376, train-prompt); IAD-R1 = its **native-prompt** run (fairest to it; full `<think>` traces).
- **100 images per benchmark**, round-robin across all products (DS-MVTec 15, VisA 12) for diversity. Overlap pool: DS-MVTec 916, VisA 549.
- **Judge inputs per trace:** original image + **red GT-mask overlay** (true defect location) + **GT defect type** (from the MMAD MCQ "What is the type of the defect?") + the model's trace. The judge is **blind to which model wrote the trace** and is told the verdict is already correct → it scores *reasoning quality* only.
- **5 axes, each 0-2** (sum = overall /10): Visual Grounding, Defect Faithfulness, Evidence-before-Conclusion, Coherence, Conciseness. (System prompt in the script + thesis App.)
- **Location and Type are scored SEPARATELY (not by the judge):** Location = predicted 3×3 cell vs GT-mask 3×3 cell (MET if overlap); Type = Nomic-embedding similarity (`nomic-embed-text-v1.5`) between predicted `<type>` and the MCQ GT type (graded; exact/substring → 1.0).

|---|---|---|---|---|---|---|---|---|---|

## Findings
- **Our model produces substantially more faithful/grounded explanations:** +4.85 on DS-MVTec (9.14 vs 4.29) and +2.27 on VisA (8.67 vs 6.40), on matched images where both detect correctly.
- IAD-R1's native DS-MVTec traces are notably weaker (often terse / missing structured tags → low grounding & evidence-order), driving the large DS gap.
- **Mechanical points:** we win Location + Type on DS-MVTec (0.82/0.56 vs 0.43/0.34). On VisA the picture is mixed — IAD-R1 edges Location (0.64 vs 0.56), Type ≈ tie (0.54 vs 0.53) — yet our judged *reasoning* is still higher.

## Caveats (honest)
- **Single judge sample (k=1)** — easy to bump to median-of-3 for the final number (~1200 calls, ~45 min).
- **Reference-guided, not reference-faithfulness:** the judge measures *plausibility/grounding-consistency* with the GT evidence, not mechanistic faithfulness (no input-perturbation flip test). A true faithfulness probe (mask the claimed region → does the verdict flip?) is separate future work.
- **Type GT** from the MMAD MCQ covers **94.8% DS-MVTec / 99.2% VisA** anomalies (subfolder fallback otherwise); VisA has fewer specific types than DS-MVTec.
- **Judge family:** traces were generated by Gemini-2.5-Flash and the judge is Gemini-3-Flash (same family); blinding to author mitigates but a cross-family judge check is future work.
