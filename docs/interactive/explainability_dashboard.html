Does it generalise? Held‑out Real‑IAD

Balanced accuracy on 4,236 Real‑IAD images that were never in any model's SFT, rollout, or GRPO pool — the closest thing here to an out-of-distribution test. Each model in its own native prompt mode.

Both base models collapse toward the 50% chance line (marked); every fine‑tuned checkpoint — regardless of recipe or backbone — lands in a tight 79–84% band. That clustering, on data none of them trained on, is the generalisation claim.

A standard-protocol check: MMAD Discrimination, fixed

MMAD (the benchmark DS-MVTec/VisA come from) defines its own multiple-choice protocol across five defect-relevant subtasks. A first pass at scoring these (2026-07-24) asked every model "answer with the letter of the correct option only" — a format Arm-C and SFT+GRPO were never trained on (both are fine-tuned on a fixed <answer>Yes/No</answer> schema). Confirmed by hand: Arm-C completed a full, sensible <think> trace and then answered in its own trained schema regardless of the letter format asked for — on 15.0% of its answers overall, scored as wrong. That conflated "doesn't know" with "won't use this format." See the concrete cases in the format-mismatch gallery.

Re-scored in each model's native answer format

Two proxy fixes were tried and rejected: per-option yes/no verification (Arm-C ignored the specific option asked and just re-ran its own open-ended diagnosis every time, always answering "Yes") and embedding-similarity matching against its free-form output. Neither reflects a real trained capability for Classification/Localization/Description/Analysis, so those four subtasks are dropped entirely — not patched, not proxied. Discrimination (is there a defect?) is different: it's genuinely binary, so it scores cleanly in each model's own native format with no proxy needed — Arm-C/SFT+GRPO via their real <answer>Yes/No</answer> trainprompt output (reusing their existing full-benchmark eval, zero new inference), base Qwen2.5-VL/Qwen3-VL via the lettered MCQ they already comply with 100% of the time (general zero-shot models have no fixed schema to violate). All four scored on the same matched 200-image sample per benchmark (100 anomalous + 100 normal).

  • Reference-guided plausibility, not mechanistic faithfulness — no input-perturbation flip test.
